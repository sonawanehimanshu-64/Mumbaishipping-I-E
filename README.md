
# Mumbaishipping I&E

A responsive import-export and shipping inquiry website based in Mumbai, India.

## Features

- Responsive website layout
- Modern dark ocean visual theme
- Three.js 3D cargo container scene
- Sea freight and air freight service sections
- Import-export and customs coordination information
- Shipping inquiry form with WhatsApp integration
- Mobile navigation
- GitHub Pages compatible static hosting

## Project Structure

Mumbaishipping-IE/
├── index.html
├── style.css
├── script.js
├── 3d-scene.js
└── README.md

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select Open with Live Server.

The website uses a Three.js CDN import map and requires an internet connection
for its 3D scene and external fonts.

## Configure WhatsApp

Open script.js and replace the placeholder WhatsApp number with your
business number in international format without +, spaces or dashes.

For an Indian number, use the format 91 followed by the 10-digit mobile number.

## Deploy on GitHub Pages

1. Push the project files to a GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the main branch and / (root).
6. Save and wait for the deployment to finish.

## Important

This is a static website. The inquiry form opens WhatsApp but does not store
inquiries in a database, calculate freight rates or provide live shipment tracking.

Business information, service claims, contact details and legal requirements
must be verified before the website is used commercially.
